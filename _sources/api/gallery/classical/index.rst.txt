cybersecuritykit.classical
==========================

Gallery examples for :mod:`cybersecuritykit.classical`. Each one reproduces a breakthrough from
:doc:`the history page </history/classical_breakthroughs>`, on toy keys, simulated
systems or synthetic data.

Each script is self-contained: download it as a Python file or a notebook, or run
it in the browser with JupyterLite.
