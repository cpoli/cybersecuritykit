cybersecuritykit.sidechannel
============================

Gallery examples for :mod:`cybersecuritykit.sidechannel`. Each one reproduces a breakthrough from
:doc:`the history page </history/sidechannel_breakthroughs>`, on toy keys, simulated
systems or synthetic data.

Each script is self-contained: download it as a Python file or a notebook, or run
it in the browser with JupyterLite.
