cybersecuritykit.classical
==========================

.. include:: /_generated/nav/classical.rst

.. automodule:: cybersecuritykit.classical
   :no-members:

Shift, polyalphabetic, digraphic and fractionating ciphers, Enigma and Lorenz,
Shannon's information theory, and the cryptanalysis that broke each of them.

Every public name below is re-exported by the subpackage: import it as
``csk.classical.<name>``. The plotting helpers are the exception: import them
explicitly from ``cybersecuritykit.classical.visualizers``, which loads Matplotlib.
