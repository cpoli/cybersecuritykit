cybersecuritykit.pqc
====================

.. include:: /_generated/nav/pqc.rst

.. automodule:: cybersecuritykit.pqc
   :no-members:

The quantum threat and its answers: Shor's period finding and Grover's search
on a simulated state vector, lattice reduction, Ajtai's SIS hash, NTRU,
learning with errors and its ring and module forms up to Kyber, lattice
signatures with aborts, McEliece and Niederreiter on Goppa codes with
information-set decoding, the multivariate schemes and the attacks that broke
them, and Winternitz, XMSS and SPHINCS hash-based signatures.

Every public name below is re-exported by the subpackage: import it as
``csk.pqc.<name>``. The plotting helpers are the exception: import them
explicitly from ``cybersecuritykit.pqc.visualizers``, which loads Matplotlib.
